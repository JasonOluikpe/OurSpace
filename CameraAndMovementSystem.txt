1.1 CameraManager (Dew.Core)
--------------------------------------------------------------------------------
Type:      CameraManager : ManagerBase<CameraManager> (singleton)
Access:    CameraManager.instance

Purpose: owns the in-game Cinemachine camera rig, follow target, zoom, shake
         routing, occlusion handling, damage vignette, and spectation.

Runtime setup
  - Creates a GameObject named "Follow Transform" at runtime, parented to the
    CameraManager object.
  - That transform is assigned as both `Follow` and `LookAt` of the active
    Cinemachine virtual camera (VCam).
  - Keeps a reference to the active entity VCam and swaps it via
    SetActiveEntityVCam().

  zoomSmoothTime          = 0.2f
  startSpectatingTime     = 3.0f
  nextSpectateTargetTime  = 2.0f

  smallDamageAlpha        = 0.2f
  bigDamageThreshold      = 0.2f
  bigDamageAlpha          = 1.0f
  minAlphaHealthThreshold = 0.5f     (50% HP)
  maxAlphaHealthThreshold = 0.25f    (25% HP)
  maxAlpha                = 0.6f
  damageOverlayDecaySpeed = 0.5f
  occlusionTestRadius     (serialized)
  disableSeeThrough       (serialized)
  zoomSteps               (serialized int)
  farZoomBody             (serialized Vector3)
  midZoombody             (serialized Vector3)
  closeZoomBody           (serialized Vector3)
  cutsceneTopLetterBox / cutsceneBottomLetterBox (RectTransforms)

Per-frame pipeline — FrameUpdate()
  1. base.FrameUpdate()

--------------------------------------------------------------------------------
1.2 Following
--------------------------------------------------------------------------------
Method: FrameUpdateFollow()

  Target position selection:
    - Single-player: focusedEntity.transform.position
    - Multiplayer (manager flag true): average of positions of all alive
      entities/heroes; falls back to the focused entity if none qualify.

  Modifiers:
    - For each CameraModifierBase in _cameraModifiers:
        if (CameraModifierOffset) target += modifier.offset;
      (skipped entirely while spectating)

  Smoothing:
    _followTransform.position = Vector3.SmoothDamp(
        _followTransform.position,
        target,
        ref _followCv,
        followSmoothTime        // 0.05f
    );

  Snap:
    SnapCameraToFocusedEntity() instantly sets the follow transform to the
    focused entity, zeroes _followCv, applies the zoom target directly, and
    toggles the Cinemachine camera enabled state.

Notes:
  - Because SmoothDamp uses 0.05s, the camera is intentionally snappy with a
    tiny lag; it is effectively glued to the player during normal movement.

1.3 Camera angle (yaw) and camera-relative input
--------------------------------------------------------------------------------
Backing fields:
  float            _entityCamAngle
  Quaternion       entityCamAngleRotation   (initialized to Quaternion.identity)

Property:
  float entityCamAngle { get; set; }

  get:
    return _entityCamAngle;

  set:

    entityCamAngleRotation   = Quaternion.Euler(0f, _entityCamAngle, 0f);

  => Setting the angle always snaps the camera, never smooths it.

Pitch:

  serialized VCam configuration, not in managed code. (Typically a fixed
  isometric-ish pitch for this genre.)

1.4 Zoom
--------------------------------------------------------------------------------
Methods: FrameUpdateZoom(), GetFollowOffsetTarget(), SetZoomLevel(),
         ZoomIn()/ZoomOut() (triggered), Awake()

State:
  int    currentZoomIndex      (backing field, default = defaultZoomLevel = 1)
  float  _zoomCv               (SmoothDamp velocity)
  int    zoomSteps             (serialized)
  Vector3 farZoomBody, midZoombody, closeZoomBody  (serialized)

Input:
  it_zoomInCamera  /  it_zoomOutCamera  (InputTrigger actions)

Normalized level:
  t = currentZoomIndex / (zoomSteps - 1)          // 0..1

Body offset selection (GetFollowOffsetTarget):
  if (t >= 0.5f)
      offset = Vector3.LerpUnclamped(midZoombody, closeZoomBody, t * 2f - 1f);
  else
      offset = Vector3.LerpUnclamped(farZoomBody, midZoombody, t * 2f);

  offset = entityCamAngleRotation * offset;        // apply camera yaw

Clamping:
  currentZoomIndex = Clamp(currentZoomIndex, 0, zoomSteps - 1)

Application:
  vcam.m_FollowOffset = Vector3.SmoothDamp(
      vcam.m_FollowOffset,
      targetOffset,
      ref _zoomCv,
      zoomSmoothTime        // 0.2f
  );

Notes:
  - Zoom is a pure follow-offset change; FOV is not animated in this code.
  - The actual body offsets are authored prefab values and are NOT present in
    the DLL (see "Unknowns" at the end).

1.7 Camera shake — FxCameraShake
--------------------------------------------------------------------------------

  float sustainTime    = 0.1f
  float decayTime      = 0.5f

Methods:
  CreateImpulseSource()
  Play()            // may run a delayed coroutine using `delay`
  DoShake()
  Stop()
  CancelAllShakes()
  SetOwnerContext(enum)
  isPlaying

CreateImpulseSource():
  if (_impulse != null) return;
  _impulse = GetComponent<CinemachineImpulseSource>() (or added);
  _impulse.m_ImpulseDefinition.m_ImpulseType = 3;      // custom/legacy impulse
  _impulse.m_ImpulseDefinition.m_RawSignal = signalSource;

DoShake() scaling:
  amplitude  *= 1.25f;
  frequency  *= 0.9f;
  attackTime *, sustainTime *, decayTime  *= 1.25f;

  context switch (5 cases):
      a mild-shake case additionally reduces amplitude by
          max(0f, amplitude - 0.6f) * 0.25f
      and halves the time envelope.

  Global multipliers are applied elsewhere (Global_AmplitudeMultiplier,
  Global_FrequencyMultiplier, Global_TimeMultiplier), and the final amplitude
  is multiplied by a settings scalar (field at metadata offset 0x04000758).

Guards:
  - Skips the impulse if CameraManager.instance == null.
  - Skips if CameraManager.isPlayingCutscene == true.

Gamepad rumble:
  Also calls InputManager.AddShakeInstance(new ShakeInstance(...)) with:
    position, frequency, amplitude, attack, sustain, decay, startTime
  ShakeInstance is a plain data object consumed by the rumble mixer.
  The static accumulated amplitude is used to budget/limit total rumble.

CancelAllShakes():
  Clears the Cinemachine impulse manager and resets accumulated static state.

Global application:
  `Ad_DamageShake` (an effect type) is the gameplay entry point that triggers
  damage-related shakes.

1.9 Damage overlay (screen vignette)
--------------------------------------------------------------------------------
Methods: FrameUpdateDamageOverlay(), ClientEntityEventOnTakeDamage(evt)

Constants:
  minAlphaHealthThreshold = 0.5f
  maxAlphaHealthThreshold = 0.25f
  maxAlpha                = 0.6f
  damageOverlayDecaySpeed = 0.5f

Per-frame target alpha from health:
  hpRatio = health / maxHealth
  _damageOverlayMinAlpha =
      Clamp01(1f - (hpRatio - maxAlphaHealthThreshold)
                    / (minAlphaHealthThreshold - maxAlphaHealthThreshold))
      * maxAlpha;
  // 0 at >=50% HP, ramps to 0.6 at <=25% HP

  alpha = MoveTowards(alpha, _damageOverlayMinAlpha,
                      damageOverlayDecaySpeed * dt);

On damage event (ClientEntityEventOnTakeDamage):
  - Ignored unless victim == focusedEntity.
  - damageRatio = damage / focusedEntity.maxHealth
      (damage type 4 is excluded; if the attacker is the focused entity the
       ratio is scaled by 0.1)
  - if damageRatio >= bigDamageThreshold (0.2)  -> alpha += 1.0f, play bigDamageShake
  - else if damageRatio >= smallDamageThreshold(0.01) -> alpha += 0.2f, play smallDamageShake
  - If focused entity is a Hero with disableDamageOverlay == true, alpha is
    forced to 0.

2.2 Speed calculation
--------------------------------------------------------------------------------
get_currentMaxAgentSpeed():
  return baseAgentSpeed
       * entity.Status.movementSpeedMultiplier
       * GetMovementSpeedMultiplierByAttack();

EntityStatus.get_movementSpeedMultiplier()
  -> reads FinalStats.movementSpeedMultiplier

FinalStats.movementSpeedMultiplier
  -> aggregated from BaseStats + BonusStats by the stats processor.

Attack-slow multiplier:
  SetAttackMovSpdDisadvantage_Imp(float duration):
      _lastAttackStartTime          = Time.time;
      _lastAttackMovSpdMultiplier   = 0.5f;
      _lastAttackMovSpdDuration     = duration * 2f;

  GetMovementSpeedMultiplierByAttack():
      elapsed = Time.time - _lastAttackStartTime;
      if (elapsed >= _lastAttackMovSpdDuration) return 1f;
      return Lerp(0.5f, 1f, elapsed / _lastAttackMovSpdDuration);

  DoAttackSlowdownTick():
      only when isLocalMovementProcessor && !isWalking;
      (drives the lerp/cleanup)

So: attacking cuts move speed to 50%, recovering linearly over 2x the attack
duration.

--------------------------------------------------------------------------------
2.4 Two movement modes
--------------------------------------------------------------------------------
Movement request is stored in `_movementVector` with a bool `isDirection`.

A) Directional mode (keyboard / gamepad)
     dir    = normalize(input)                    (magnitude clamped to 1)
     vel    = currentMaxAgentSpeed * dir
     walk   = input.magnitude
     agent.velocity = Vector3.zero
     DoVelocityUpdate(vel)

B) Destination mode (click-to-move)
     vel    = agent.desiredVelocity.normalized
              * currentMaxAgentSpeed
              * _destinationMovementSpeedMultiplier
     walk   = _destinationMovementSpeedMultiplier
     (agent path drives direction; avoidance handled by NavMesh)

Path completion check:
  if (agent.path destination is within 0.1 squared distance of nextPosition):
      reset path and clear movement.

Position application:
  transform.position = agent.nextPosition;
  transform.position = NavSnapYCached(transform.position);
  transform.position = GroundSnapCached(transform.position);

  _localVelocity = DoVelocityUpdate(...);
  agent.nextPosition = transform.position + _localVelocity * dt;

Rotation:
  desiredYaw = direction of _localVelocity;
  DoRotateTowardsDesiredAngleTick();

Walk smoothing:
  if targetWalk == 0 && currentWalk > 0:
      walk = MoveTowards(walk, 0, dt * 20f);


--------------------------------------------------------------------------------
2.5 Velocity update (the core smoothing)
--------------------------------------------------------------------------------
DoVelocityUpdate(Vector3 movement):
  currentSpeed = localVelocity.magnitude;
  targetSpeed  = movement.magnitude;

  accel = normalizedAcceleration * currentMaxAgentSpeed;
  if (stopping or speedMultiplier ~= 0)
      accel = Clamp(baseAgentSpeed, 0.1f, 1000f) * 5f;

  speed = MoveTowards(
      currentSpeed,
      targetSpeed,
      accel * dt * (currentSpeed > targetSpeed ? 2f : 1f)
  );

  targetYaw = atan2 of movement (x,z)
  yaw = MoveTowardsAngle(
      currentYaw,
      targetYaw,
      rotateSpeed * movementSpeedMultiplier * dt
  );

  velocity = Quaternion.Euler(0, yaw, 0) * Vector3.forward * speed;
  return velocity;

DoRotateTowardsDesiredAngleTick():
  _currentYaw = Mathf.SmoothDampAngle(
      _currentYaw,
      desiredYaw,
      ref _desiredAngleCv,
      rotationSmoothTime * (angleDiff < 60f ? 2f : 1f)
  );

  // note: smaller smoothing time when the turn is shallow => snappier small
  //       corrections, slower/larger smoothing on big turns.

2.7 Dash builder
--------------------------------------------------------------------------------
Dash fields / defaults:
  distance              = 2.25f
  duration              = 0.25f
  DewEase ease          = DewEase.Linear (0)
  rotateForward         = true
  affectedByMovementSpeed = false
  useLinearSweep        = true
  canGoOverTerrain      = false

=> Implied dash speed = 2.25 / 0.25 = 9.0 units/second.

ApplyByDirection(Entity entity, Vector3 dir, Action onFinish):
  start    = entity.agentPosition;
  target   = start + dir.normalized * distance;

  if (useLinearSweep)
      destination = Dew.GetValidAgentDestination_LinearSweep(start, target);
  else
      destination = Dew.GetValidAgentDestination_Closest(start, target);

  var disp = new DispByDestination {
      destination            = destination,
      duration               = duration,
      ease                   = ease,
      canGoOverTerrain       = canGoOverTerrain,
      isCanceledByCC         = true,
      isFriendly             = true,     // => isDashing
      rotateForward          = rotateForward,
      affectedByMovementSpeed= affectedByMovementSpeed,
  };

  onFinish?.Invoke();                  // callback slot wired by the ability
  entity.Control.StartDisplacement(disp);
  return disp;

ApplyByDestination(Entity entity, Vector3 destination, Action onFinish):
  return ApplyByDirection(entity, destination - entity.agentPosition, onFinish);


--------------------------------------------------------------------------------
2.8 Displacement execution — DoDisplacement
--------------------------------------------------------------------------------
StartDisplacement(Displacement disp):
  Server-only entry point:
    - logs a warning and returns if !NetworkServer.active
    - if disp is not friendly AND entity.Status.hasCrowdControlImmunity
        -> CancelImmediately(disp)
    - if !disp.isAlive
        -> CancelImmediately(disp)
    - otherwise stores OngoingDisplacementInternalData and begins.

Per-frame (DoDisplacement):
  Cancellation:
    - cancels if crowd control / invulnerable / unstoppable conditions apply
      when disp.isCanceledByCC is true
    - validates disp.isAlive

  Speed multiplier:
    mult = disp.affectedByMovementSpeed
             ? EntityStatus.movementSpeedMultiplier
             : 1f;
    if (entity is Hero) mult = Min(mult, 2.5f);

  For DispByDestination:
    t      = Clamp01(elapsedTime / duration);
    easedT = DewEase(ease, t);

    Convert start/end to 2D (XZ):
      if (horizontalDistanceSqr < 0.01)
          use previous position (prevents degenerate direction)
      else
          build an A->B transform matrix and evaluate the cubic Bezier
          from `curve` (Vector4 control points), optionally reprojected by
          curveHorizontalDistance.

    y = Lerp(start.y, destination.y, easedT);

  Speed-multiplier integration:
    destination += delta * (mult - 1f);
    delta       *= mult;
    target       = lastPosition + delta;

  Move:
    if (agent is on NavMesh) { agent.Move(delta); transform.position = agent.nextPosition; }
    else                     { transform.position += delta; }

  Rotation:
    if (rotateForward)  SetRotation(delta, rotateSmoothly);
    else                DoRotateTowardsDesiredAngleTick();

  Completion:
    when elapsedTime > duration:
      ongoingDisplacement = null;
      _dispData = default;
      onFinish?.Invoke();
      ClientEvent_OnDisplacementFinished();

Status properties:
  get_isDashing()   = isDisplacing && ongoingDisplacement.isFriendly
  get_isDodging()   = isDisplacing && ongoingDisplacement.isDodging
  get_isDisplacing()= displacement != null

  return (Time.unscaledTime - _lastMovementDirectionUnscaledTime) < 0.4f;

GetCharInputOfMove():

  MOUSE (it_move held):
    if cursor is over an enemy and the setting is enabled:
        DoAttackMoveAtCursor(2, false);
    else:
        MoveToCursor();
        -> isMovementSchemeDirectional = false;
        -> entity.Control.MoveToDestination(cursorGroundPos, true, 1f);

    Continuous dispatch while held:
      every 0.0625s re-dispatch the destination.
      If the cursor is within ~1 unit of the player, compute a fallback
      destination 1 unit from the cursor using camera pitch:
          offset = 1f / tan(-cameraEulerX * Deg2Rad)
      and validate via Dew.GetValidAgentDestination_Closest.

  KEYBOARD / GAMEPAD:
    input = DewInput.GetLeftJoystick();
    WASD is synthesized when in gamepad mode and the relevant setting is on;
    magnitude clamped to 1;
    inverted-controls setting negates the vector.

    if (input.sqrMagnitude > 0.0001f):
        isMovementSchemeDirectional = true;
        lastMovementDirection  = normalize(
            CameraManager.instance.entityCamAngleRotation * new Vector3(x, 0, y)
        );
        lastMovementStrength   = input.magnitude;
        _lastMovementDirectionUnscaledTime = Time.unscaledTime;

        Dispatch at 60 Hz:
          entity.Control.SetMovementState(
              lastMovementDirection * (0.4f + 0.6f * lastMovementStrength),
              isDirection: true
          );

    if (no input && was doing directional movement):
        entity.Control.ClearMovement();

Camera-relative detail:
  The multiplier (0.4 + 0.6 * strength) means even a light stick tilt moves at
  40% speed, scaling linearly to 100% at full tilt. Digital WASD is full
  strength (1.0).

2.11 Networking (Mirror)

  priority based on whether the entity is the local player or an NPC, to keep
  crowds from jittering.

  UpdateLastMoveTime() — server-only; records lastMoveTime (for idle/AFK logic
  and combat-state tracking).

PART 5 — IMPLEMENTATION NOTES (for a clone)
================================================================================

If reproducing in another engine (e.g. Panda3D):

Camera
  - Keep a virtual pivot that SmoothDamps toward the player at 0.05s.
  - Store a single yaw angle; rotate the fixed offset by it.
  - Zoom = interpolate between three offset vectors by a normalized level.
  - Shake = decaying sine/noise added to the final camera position; scale
    amplitude by damage severity.

Movement
  - Input -> desired velocity; accelerate toward it at 4 * maxSpeed,
    decelerate at 8 * maxSpeed.
  - Rotate yaw toward velocity at 720 deg/s.
  - Camera-relative WASD: rotate input vector by camera yaw.
  - Dash: constant-velocity or eased 2.25-unit move over 0.25s, with a navmesh
    line-sweep clamp and CC cancellation.
